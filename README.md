# FeedFlow Downloads

Public release installers for FeedFlow Host and Client.

## Asset naming

- Windows Host: `FeedFlow-Host-Setup-X.Y.Z.exe`
- Windows Client: `FeedFlow-Client-Setup-X.Y.Z.exe`
- Android Client: `FeedFlow-Client-X.Y.Z.apk` or `app-client-release.apk`

Use semantic release tags such as `v1.0.6`. Draft releases are ignored by the updater. SHA-256 asset digests are verified before installation.
